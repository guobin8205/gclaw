布局结构（从上到下）

┌─ Transcript（对话区，flex-grow）
│ ├─ Banner（版本 + 模型 + 模式）
│ ├─ 消息列表（可滚动，虚拟滚动）
│ │ ├─ User messages（❯ 前缀）
│ │ ├─ Assistant messages（缩进）
│ │ └─ Tool calls（⚙ 图标 + 文件名）
│ └─ Scrollbar（右侧 1 列宽）
├─ Divider（分隔线）
├─ Composer（输入区，flex-shrink=0）
│ ├─ Status Rule（模型 + 上下文 + 时间）
│ ├─ Queue Preview（排队消息预览）
│ ├─ Completions Dropdown（浮动补全）
│ └─ Input Line（❯ 提示符 + 文本输入）
└─

交互功能清单

Tab 补全 / 触发斜杠命令补全，Tab 应用，↑↓ 切换
历史记录 ↑↓ 浏览历史，持久化到 ~/.gclaw/history
多行输入 \ + Enter 换行，Enter 发送，显示多行缓冲区
消息队列 Agent 忙碌时排队，预览队列内容，可编辑
/logs [N] 在对话区显示最近 N 行日志（hermes 方式）
Ctrl+C 中断当前 agent 运行，Esc 取消当前输入
/interrupt 注入中断消息到运行中的 agent
