输入系统交互规范

Enter 发送消息（单行模式直接发送）
Ctrl+Enter 换行（插入新行到多行缓冲区）
Backspace 删除光标前字符，行首时合并到上一行
Delete 删除光标后字符
← → Home End 光标移动（跨行）
Ctrl+V 粘贴文本；若剪贴板含图片则附加为图片附件
Ctrl+I / 拖拽文件 附加文件到消息（图片走 Vision，文本直接注入）
Ctrl+C 空输入时中断 agent；有输入时清空当前输入
Esc 取消当前输入/关闭补全下拉
↑ ↓ 无补全时浏览历史；有补全时切换选项
Tab 应用当前补全建议

图片/文件处理流程

Ctrl+V (clipboard has image)
→ 保存为 ~/.gclaw/tmp/clipboard-{ts}.png
→ 底部显示附件标签 🖼 clipboard-image.png ✕
→ 发送时自动调用 vision 工具分析
Ctrl+I / drag file
→ .png/.jpg/.jpeg → 图片附件（走 vision）
→ .txt/.log/.md → 文本附件（注入到 prompt）
→ 其他格式 → 提示不支持
